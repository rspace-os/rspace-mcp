## Example (replace this)

### Registering a new sample

**Trigger:** a new physical sample enters the lab and needs an RSpace record.

**Steps:**

1. Check whether a sample template already exists for this sample type; use it if so.
2. Create the sample using the template, or a plain sample record if none exists.
3. Fill in: source, date received (ISO 8601), storage location, and responsible researcher.
4. Link the sample to the relevant project notebook.
5. If the sample relates to an existing experiment, cross-reference the experiment document.

### Start a new experiment document

**Trigger:** starting a new experiment inside a project.

**Steps:**

1. Name the document `YYYY-MM-DD_<short-description>`.
2. File it inside the relevant project notebook, not the top level workspace.
3. Link back to the protocol or SOP being followed, if one exists.
4. ...
